# OmniGuard 🛡️ — System Storage Forensic & DevSecOps Audit Toolkit

OmniGuard is an ultra-high performance, production-grade command-line utility tool designed to act as an all-in-one workstation cleaner, storage forensic mapping framework, and data safety compliance checker. It targets recursive directory architectures to resolve actual everyday system clutter while keeping sensitive organizational data audited.

## 🌟 Primary Capabilities

*   **Multi-Threaded Hashing Pipeline**: Uses multi-threaded workflows to map recursive files down to cryptographic SHA-256 and MD5 unique signatures concurrently.
*   **Storage Redundancy Deduplication Engine**: Detects absolute layout duplicates matching content bit-for-bit, calculating explicit **recoverable system storage memory** down to precision blocks.
*   **PII Compliance Risk Engine**: Scans text configs, source maps, log targets, and storage files for data privacy leaks, tracking regex matches like explicit Emails, API secret keys, Auth tokens, and Credit Cards.
*   **Instant Structural Telemetry Reports**: Creates comprehensive structured documentation loops by auto-exporting execution metrics to flat `CSV` relational maps and `JSON` analytics graphs.

## 🛠️ Step-by-Step Installation & Usage Recipe

### Prerequisites
*   Python 3.8 or above installed on the architecture system environment.
*   Zero external dependencies required (`Standard Library Native Power`).

### Command Execution Execution
Clone or move these repository distribution elements inside your computer directory setup, launch your system terminal panel, and execute the following commands:

```bash
# Basic Execution: Run forensic storage checks on the current directory context
python omniguard.py

# Advanced Execution: Target a specific custom heavy workspace directory with PII Security Scanning enabled
python omniguard.py /path/to/your/heavy/computer/directory --scan-pii
```

### Generated Output Assets
Upon execution loop finalization, the system immediately returns:
1.  **Terminal Console UI Dashboard**: Displays metrics cleanly structured with custom built-in runtime ASCII progress mapping controls.
2.  `omniguard_report.json`: Deep telemetry matrix tracking all file system attributes and risk violations.
3.  `omniguard_duplicates.csv`: Organized map grouping exact clones together for safe removal or cleanup.
